# Assignment Portfolio

A simple personal portfolio website built with HTML and CSS.

## Overview

This project showcases a portfolio layout with a clean, modern design and responsive styling. It includes:

- a hero section
- project highlights
- contact details
- polished visual styling

## Files

- `index.html` — the portfolio page structure
- `style.css` — styling and layout

## Run locally

Open `index.html` in a browser to view the portfolio.

You can also serve it locally with a simple HTTP server, for example:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.

## Project status

This is a static portfolio website ready to be customized with your own content, projects, and links.
